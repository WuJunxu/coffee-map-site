# 世界咖啡产区与庄园分布图

一张把**产区属性全部叠在同一张图上**的世界咖啡地图：国家用面状填色表示产量，产区用点状符号表示，
点的大小＝海拔中值、形状＝豆种大类、色相可切换（处理法 / 烘焙度 / 豆种 / 风味族）。

- **主图**：`index.html`
- **国家级细部图**：`countries/` 下 45 张（墨卡托投影，自适应该国范围，含定位插图与产区名册）
- 收录 **107 个产区／庄园群**，分属 **45 个国家/地区**；其中 **24 个产区带「著名子产区」共 77 个**

## 三种进入国家级图的方式

1. 在主图**双击**某国国界
2. 点击国家详情卡里的跳转按钮
3. 用工具栏「国家产区图」下拉框

## 在图上能读到什么

| 视觉变量 | 含义 |
|---|---|
| 面状填色 | 生豆年产量（7 级，USDA FAS 量级近似） |
| 点大小 | 海拔中值 |
| 点形状 | 圆＝阿拉比卡，菱形＝罗布斯塔，环＝兼产 |
| 点色相 | 可切换：处理法 · 烘焙度 · 豆种 · 风味族 |
| 金色小点 | 该产区有你自己写的「口味描述」 |

交互：拖动平移、滚轮或左侧控制条缩放（`＋ － 0 F` 与方向键）、双击国界下钻、搜索框支持产区／子产区／国家／风味／自填笔记。

## 「口味描述」是你自己的笔记本

每个产区都能自填一段文本，增 / 改 / 删随时可操作，`⌘/Ctrl+Enter` 保存。
写在**浏览器本地**（localStorage，键名 `coffee-map.taste.v1`），只对本机本浏览器生效，不上传；
换浏览器或清缓存会丢，重要内容请自行另存。

## 关于子产区的两个坑

- **层级各国不统一**：埃塞俄比亚是 woreda 或水洗站，哥伦比亚与巴西是市镇，肯尼亚是合作社水洗站，
  巴拿马是庄园地块。所以每个子产区都带「单元类型」标签（行政区 / 处理站 / 庄园 / 地块 / 法定产区），
  比较前先看这一格。
- **名字常被当成产地**：比如「花魁」不是品种也不是独立产区，而是 2017 年起中国市场对
  **Hambella（罕贝拉）Buku Abel 处理厂**日晒批次的命名 —— 花魁 ⊂ 罕贝拉 ⊂ 古吉。

## 数据口径

- **底图**：Natural Earth 1:110m（主图）／1:50m（国家图）；**中国国界采用国家测绘标准口径绘制**，
  完整包含台湾岛、藏南、阿克赛钦与南海诸岛。
- **产量**：USDA FAS 量级近似值，仅用于分级，不作精确统计引用。
- **海拔 / 品种 / 处理法 / 风味**：产区层面的常见区间与典型描述，同一产区内不同庄园会有差异。
- **烘焙度不是产区属性**，而是烘焙商针对该产区豆性的常见选择区间 —— 应读作"通常被烘成什么"，
  而非"应该烘成什么"。
- **子产区**只在"该名字在市面上被单独标名流通"时才收录，没有可靠子产区的一律留空。
